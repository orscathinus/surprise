# DEEP TIME — Update 1.1

An interactive natural-history museum built as a dependency-free static site for GitHub Pages.

## What's new in 1.1

- A much denser 4.54-billion-year time machine with 18+ dated events and detailed field-note dialogs
- Six visually distinct geological rooms from the Hadean through the Cenozoic
- Four switchable ecosystem dioramas with clickable organism labels
- A six-part **How We Know** evidence lab covering zircon dating, stratigraphy, isotopes, fossils, ice cores, and impact evidence
- Interactive paleogeography and atmosphere simulators
- A richer Big Five mass-extinction console with drivers, evidence, victims, aftermath, and a survival visualization
- A 12-object specimen cabinet with persistent discovery progress
- One-day, one-year, and one-kilometer deep-time scale modes
- Museum-wide client-side search and a random-exhibit button
- Responsive mobile behavior, reduced-motion support, scroll effects, and optional user-activated ambient audio
- Credited public scientific imagery from NASA/JPL and Wikimedia Commons

The site uses no framework, package install, API key, or build step.
