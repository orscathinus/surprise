# DEEP TIME — Update 1.2

A vivid, interactive, multi-page natural-history museum tracing 4.54 billion years of Earth history.

## Update 1.2 highlights

- Multi-page museum architecture for GitHub Pages
- Dedicated pages for major exhibits and geologic periods
- Site-wide search and a master page directory
- Expanded deep-time timeline, evidence lab, extinction exhibit, specimen cabinet, atmosphere lab, paleogeography, fossilization, and evolutionary innovations
- Richer era-specific visual palettes, motion, and interactive controls
- Reusable scientific imagery from NASA, USGS, Smithsonian, and Wikimedia Commons with in-page credits
- Responsive design, keyboard focus states, reduced-motion support, and lazy-loaded images

Open `index.html` or visit the GitHub Pages deployment for the museum entrance.
