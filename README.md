# DEEP TIME

**Deep Time — A Museum of a Living Planet** is a self-contained interactive website about Earth's 4.54-billion-year history.

It is designed specifically for GitHub Pages: no framework, no build step, no dependencies.

## Highlights

- Animated starfield and rotating planet hero
- Interactive 24-hour Earth-history time machine
- Geological eon/era strata
- Interactive “Big Five” mass-extinction console
- Canvas-based planetary pulse visualization
- Responsive layouts and reduced-motion accessibility
- Optional ambient Web Audio soundscape (user-activated only)

## GitHub Pages

Serve the repository root from the `main` branch. `index.html` is the entry point.
